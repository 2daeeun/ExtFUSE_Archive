# Git Metadata Inventory Before Deletion

**English** | [한국어](README.ko.md)

This directory records the repository states immediately before the five
nested `.git` directories were deleted. It contains no secrets; remote URLs
were normalized to public GitHub addresses.

For reproducibility, the original absolute worktree paths and the names and
email addresses recorded by Git for authors, committers, and reflogs were
retained. These are not credentials, but they may be considered personal
information when distributing the archive publicly; review them separately
if needed.

## Files

- `*.state.txt`: each actual checkout's HEAD, branch/detached state, upstream,
  describe output, status porcelain v2, object statistics, branches/refs,
  reflogs, worktrees, sanitized local config, hook list/checksums, and use of
  special features
- `linux.refs.tsv`: 616 Linux local/remote/tag refs and their original URLs
- `libfuse.refs.tsv`: 130 libfuse refs from the union of the two checkouts,
  with their original URLs
- `extfuse.refs.tsv`: three extfuse refs and their original URLs
- `object-integrity.txt`: object pack sizes and SHA-256 checksums, duplicate
  pack information, and fsck results

The Linux and libfuse `*.refs.tsv` files contain the union of refs from the
baseline and ExtFUSE checkouts, including local branches present in only
one checkout.

All five indexes and working trees were clean at the time of inspection.
There were no shallow clones, partial clones, alternates, additional worktrees,
custom hooks, Git notes, replace refs, stashes, submodules/gitlinks, or Git LFS
files. The only hook files were the 14 default `*.sample` files generated by Git.
